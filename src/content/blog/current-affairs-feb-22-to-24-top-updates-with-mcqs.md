<h3>International Relations and Summits</h3>
<ul>
<li><strong>1. Signatories to New Delhi Declaration on AI reach 91 (Feb 24):</strong> Following the India-AI Impact Summit (Feb 16–21), three more nations—Bangladesh, Costa Rica, and Guatemala—officially joined the "New Delhi Declaration" on February 24, bringing the total to 91 signatories. The framework is guided by the principle of “Sarvajan Hitaya, Sarvajan Sukhaya” (Welfare for all), focusing on the democratic diffusion and equitable sharing of AI benefits.</li>

<li><strong>2. India Joins "Pax Silica" Coalition:</strong> India officially became the 12th member of the US-led Pax Silica coalition. This strategic alliance aims to build resilient global supply chains for semiconductors and critical minerals.</li>
<li><strong>3. India-US AI Opportunity Partnership:</strong> Alongside the AI summit, India and the USA signed a bilateral joint statement to collaborate on AI-driven economic growth and sovereign AI infrastructure.</li>
<li><strong>4. India-Israel Strategic Bond:</strong> Prime Minister Modi highlighted the growing strength of India-Israel ties ahead of a high-level visit, focusing on technological collaboration and Blue Food Security.</li>
</ul>
<!--more-->
<hr />

<h3>Defence and Space</h3>
<ul>
<li><strong>5. Exercise Dharma Guardian 2026:</strong> The 7th edition of the joint military exercise between India and Japan commenced on February 24 at Chaubattia, Uttarakhand. It focuses on urban warfare and counter-terrorism.</li>
<li><strong>6. DefSat Conference and Expo 2026:</strong> The 4th edition began in New Delhi (Feb 24–26) with the theme "Space at the Core to National Security." It integrates space-based services into India’s tri-services and border security.</li>
<li><strong>7. IndSpaceX Wargame 4.0:</strong> As part of DefSat 2026, this wargame was launched to simulate contested space domains and test India’s mission resilience in satellite-based communications.</li>
</ul>

<hr />

<h3>National Infrastructure and Economy</h3>
<ul>
<li><strong>8. Namo Bharat RRTS Inauguration (Feb 22):</strong> PM Modi dedicated the Delhi-Meerut Namo Bharat Corridor to the nation. This is India’s first Regional Rapid Transit System (RRTS).</li>
<li><strong>9. Semiconductor Groundbreaking in UP:</strong> A groundbreaking ceremony was held for the HCL-Foxconn and India Chip Limited semiconductor units in Uttar Pradesh, signaling a major boost to the "India Semiconductor Mission."</li>
<li><strong>10. Export Promotion Mission (EPM) Expansion:</strong> Union Minister Piyush Goyal launched 7 additional interventions under the EPM to help MSMEs boost exports and compete globally.</li>
<li><strong>11. Golden Jubilee of Bonded Labour Act:</strong> On February 22, the Government of India marked the 50th year (Golden Jubilee) of the Bonded Labour System (Abolition) Act, 1976.</li>
</ul>

<hr />

<h3>Science, Tech and Finance</h3>
<ul>
<li><strong>12. Sarvam AI Frontier Models:</strong> Indian startup Sarvam AI unveiled two massive language models—Sarvam-30B and Sarvam-105B—positioning India as a creator of frontier AI technology.</li>
<li><strong>13. Sarvam Kaze Smart Glasses:</strong> India’s first AI-powered smart glasses, Sarvam Kaze, were launched as a domestic alternative to global wearable tech like Ray-Ban Meta.</li>
<li><strong>14. ICICI PF NPS Swasthya Equity Plus:</strong> ICICI Prudential launched India’s first health-integrated pension scheme, blending retirement savings with healthcare benefits under the NPS.</li>
<li><strong>15. UPI One World Extension:</strong> NPCI extended the 'UPI One World' wallet service to foreign delegates from over 40 countries, allowing them to experience India’s digital payment ecosystem seamlessly.</li>
</ul>

<hr />

<h3>Sports and Awards</h3>
<ul>
<li><strong>16. Ellyse Perry’s 350th Milestone (Feb 22):</strong> Australian legend Ellyse Perry became the first Australian cricketer to play 350 international matches across all formats.</li>
<li><strong>17. Vaishnavi Adkar’s Historic Final:</strong> 21-year-old tennis star Vaishnavi Adkar became the first Indian woman since 2009 to reach the singles final of a W100 tournament.</li>
<li><strong>18. FIH Pro League Update:</strong> The Indian men's hockey team split points with Spain in a high-octane match on Feb 24, strengthening their position in the Pro League standings.</li>
</ul>

<h3>Important Days and Themes</h3>
<ul>
<li><strong>19. World Thinking Day (Feb 22):</strong> Observed by Girl Scouts and Girl Guides globally. The 2026 theme is “Our Friendship.”</li>
<li><strong>20. World Scout Day (Feb 22):</strong> Celebrated to honor the birth anniversary of Robert Baden-Powell, the founder of the Scouting movement.</li>
</ul>

<script>
(function(){
  function initSmartAdviceQuiz(){
document.querySelectorAll(".qd-quiz-wrap").forEach(function(wrap) {
if (wrap._tsaInit) return;
wrap._tsaInit = true;
const options = wrap.querySelectorAll(".qd-option");
const progressBar = wrap.querySelector(".qd-progress-bar");
const percentage = wrap.querySelector(".qd-percentage");
const attemptedCount = wrap.querySelector("#qd-attemptedCount");
const correctCount = wrap.querySelector("#qd-correctCount");
const wrongCount = wrap.querySelector("#qd-wrongCount");
const message = wrap.querySelector("#qd-message");
const resetButton = wrap.querySelector(".qd-reset-btn");
if (options.length === 0) return;
const totalQuestions = new Set(Array.from(options).map(opt => opt.getAttribute("data-question"))).size;
let attempted = 0;
let correct = 0;
options.forEach(opt => {
let newOpt = opt.cloneNode(true);
opt.parentNode.replaceChild(newOpt, opt);
newOpt.addEventListener("click", function() {
const qId = this.getAttribute("data-question");
const isCorrect = this.getAttribute("data-correct") === "true";
const siblingOpts = wrap.querySelectorAll(`.qd-option[data-question="${qId}"]`);
const alreadyAnswered = Array.from(siblingOpts).some(o => o.classList.contains("qd-answered"));
if (alreadyAnswered) return;
attempted++;
siblingOpts.forEach(o => o.classList.add("qd-answered"));
if (isCorrect) {
correct++;
this.classList.add("qd-correct");
} else {
this.classList.add("qd-wrong");
siblingOpts.forEach(o => {
if (o.getAttribute("data-correct") === "true") {
o.classList.add("qd-correct");
}
});
}
const exp = wrap.querySelector(`.qd-exp[data-question="${qId}"]`);
if (exp) exp.style.display = "block";
if (attemptedCount) attemptedCount.textContent = attempted;
if (correctCount) correctCount.textContent = correct;
if (wrongCount) wrongCount.textContent = attempted - correct;
if (progressBar && percentage) {
const pct = (attempted / totalQuestions) * 100;
progressBar.style.width = pct + "%";
percentage.textContent = Math.round(pct) + "%";
}
if (attempted === totalQuestions && message) {
if (correct === totalQuestions) {
message.textContent = "CONGRATULATIONS! YOU GOT ALL CORRECT!";
} else if (correct >= totalQuestions / 2) {
message.textContent = "GREAT JOB! YOU'RE DOING WELL!";
} else {
message.textContent = "KEEP PRACTICING. YOU CAN IMPROVE!";
}
}
});
});
if (resetButton) {
let newReset = resetButton.cloneNode(true);
resetButton.parentNode.replaceChild(newReset, resetButton);
newReset.addEventListener("click", function() {
wrap.querySelectorAll(".qd-option").forEach(o => {
o.classList.remove("qd-correct", "qd-wrong", "qd-answered");
});
wrap.querySelectorAll(".qd-exp").forEach(e => {
e.style.display = "none";
});
attempted = 0;
correct = 0;
if (attemptedCount) attemptedCount.textContent = "0";
if (correctCount) correctCount.textContent = "0";
if (wrongCount) wrongCount.textContent = "0";
if (progressBar) progressBar.style.width = "0%";
if (percentage) percentage.textContent = "0%";
if (message) message.textContent = "PRACTICE REGULARLY!";
});
}
});
  }
  if (document.readyState === "loading") {
document.addEventListener("DOMContentLoaded", initSmartAdviceQuiz);
  } else {
initSmartAdviceQuiz();
  }
})();
</script>
