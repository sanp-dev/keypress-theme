<h2>Daily Current Affairs – 25 February 2026</h2>

<h3>1. PM Narendra Modi’s State Visit to Israel Begins</h3>
<p>Prime Minister Narendra Modi left India on 25 February 2026 for a two-day state visit to Israel. The visit focuses on strengthening cooperation in technology, defence, innovation, and strategic partnerships between the two nations.</p>

<h3>2. Union Cabinet Approves Renaming of Kerala to ‘Keralam’</h3>
<p>The Union Cabinet cleared the proposal to rename Kerala as “Keralam,” aligning the official English name with Malayalam usage. The constitutional procedure under Article 3 will follow before the change becomes official.</p>

<p style="padding:12px;background:#f8fafc;border-left:4px solid #1a73e8;border-radius:4px;font-weight:600;margin:16px 0;">Also Read: <a href="/post/top-current-affairs-3-to-6-march-2026-india/" style="color:#1a73e8;text-decoration:underline;">Top Current Affairs 3–6 March 2026: India and World Updates with MCQs</a></p>



<h3>3. Nationwide HPV Vaccination Drive Highlighted</h3>
<p>The Government of India outlined plans for a nationwide Human Papillomavirus (HPV) vaccination campaign to prevent cervical cancer. The drive will target girls in the eligible age group and aims to reduce cancer incidence across the country.</p>

<h3>4. Srinagar Airport Civil Enclave Project Approved</h3>
<p>The Cabinet Committee on Economic Affairs (CCEA) sanctioned ₹1,677 crore for the development of a modern civil enclave at Srinagar International Airport to improve aviation infrastructure and connectivity in Jammu and Kashmir.</p>

<p style="padding:12px;background:#f8fafc;border-left:4px solid #1a73e8;border-radius:4px;font-weight:600;margin:16px 0;">Also Read: <a href="/post/weekly-current-affairs-jan-26-to-feb-1/" style="color:#1a73e8;text-decoration:underline;">Top 30 Weekly Current Affairs (Jan 26 - Feb 1, 2026): Budget, Awards and Sports Recap</a></p>



<h3>5. Air Ambulance Crash in Jharkhand</h3>
<p>An air ambulance crashed in Jharkhand’s Chatra forest, resulting in the death of all passengers and crew members on board. Authorities have initiated an investigation into the cause of the crash.</p>

<h3>6. NCERT Textbook Debate on Judiciary Corruption</h3>
<p>The inclusion of references to corruption at various levels of the judiciary in a Class 8 NCERT Social Science textbook sparked public and political debate.</p>

<p style="padding:12px;background:#f8fafc;border-left:4px solid #1a73e8;border-radius:4px;font-weight:600;margin:16px 0;">Also Read: <a href="/post/current-affairs-17-18-19-march-national-international/" style="color:#1a73e8;text-decoration:underline;">Current Affairs 17-19 March 2026: Top 30 Updates</a></p>



<h3>7. Maharashtra Class 12 Paper Leak Investigation</h3>
<p>The Maharashtra Class 12 board examination paper leak case came under investigation, with authorities probing the involvement of coaching centres and other individuals.</p>

<h3>8. 19th All-India Police Shooting Championship Begins</h3>
<p>The 19th All-India Police Shooting Championship commenced at Reoti Ranges in Indore, with participation from state and central police teams across India.</p>

<h3>9. Delhi to Host First International Film Festival (IFFD)</h3>
<p>Delhi announced it will host its first International Film Festival Delhi (IFFD) from 25–31 March at Bharat Mandapam, aiming to promote global cinema and cultural exchange.</p>

<h3>10. Karnataka Honour Killing Bill 2026 Sparks Debate</h3>
<p>The proposed Karnataka Honour Killing and Related Offences Bill, 2026 triggered political and social discussions regarding its provisions and implications.</p>

<h3>11. DNPA Conclave 2026 Scheduled in New Delhi</h3>
<p>The Digital News Publishers Association (DNPA) Conclave 2026 is scheduled to be held on 26 February in New Delhi, focusing on the future of digital journalism in the AI era.</p>

<script>
(function(){
  function initSmartAdviceQuiz(){
document.querySelectorAll(".qd-quiz-wrap").forEach(function(wrap) {
if (wrap._tsaInit) return;
wrap._tsaInit = true;
const options = wrap.querySelectorAll(".qd-option");
const progressBar = wrap.querySelector(".qd-progress-bar");
const percentage = wrap.querySelector(".qd-percentage");
const attemptedCount = wrap.querySelector("#qd-attemptedCount");
const correctCount = wrap.querySelector("#qd-correctCount");
const wrongCount = wrap.querySelector("#qd-wrongCount");
const message = wrap.querySelector("#qd-message");
const resetButton = wrap.querySelector(".qd-reset-btn");
if (options.length === 0) return;
const totalQuestions = new Set(Array.from(options).map(opt => opt.getAttribute("data-question"))).size;
let attempted = 0;
let correct = 0;
options.forEach(opt => {
let newOpt = opt.cloneNode(true);
opt.parentNode.replaceChild(newOpt, opt);
newOpt.addEventListener("click", function() {
const qId = this.getAttribute("data-question");
const isCorrect = this.getAttribute("data-correct") === "true";
const siblingOpts = wrap.querySelectorAll(`.qd-option[data-question="${qId}"]`);
const alreadyAnswered = Array.from(siblingOpts).some(o => o.classList.contains("qd-answered"));
if (alreadyAnswered) return;
attempted++;
siblingOpts.forEach(o => o.classList.add("qd-answered"));
if (isCorrect) {
correct++;
this.classList.add("qd-correct");
} else {
this.classList.add("qd-wrong");
siblingOpts.forEach(o => {
if (o.getAttribute("data-correct") === "true") {
o.classList.add("qd-correct");
}
});
}
const exp = wrap.querySelector(`.qd-exp[data-question="${qId}"]`);
if (exp) exp.style.display = "block";
if (attemptedCount) attemptedCount.textContent = attempted;
if (correctCount) correctCount.textContent = correct;
if (wrongCount) wrongCount.textContent = attempted - correct;
if (progressBar && percentage) {
const pct = (attempted / totalQuestions) * 100;
progressBar.style.width = pct + "%";
percentage.textContent = Math.round(pct) + "%";
}
if (attempted === totalQuestions && message) {
if (correct === totalQuestions) {
message.textContent = "CONGRATULATIONS! YOU GOT ALL CORRECT!";
} else if (correct >= totalQuestions / 2) {
message.textContent = "GREAT JOB! YOU'RE DOING WELL!";
} else {
message.textContent = "KEEP PRACTICING. YOU CAN IMPROVE!";
}
}
});
});
if (resetButton) {
let newReset = resetButton.cloneNode(true);
resetButton.parentNode.replaceChild(newReset, resetButton);
newReset.addEventListener("click", function() {
wrap.querySelectorAll(".qd-option").forEach(o => {
o.classList.remove("qd-correct", "qd-wrong", "qd-answered");
});
wrap.querySelectorAll(".qd-exp").forEach(e => {
e.style.display = "none";
});
attempted = 0;
correct = 0;
if (attemptedCount) attemptedCount.textContent = "0";
if (correctCount) correctCount.textContent = "0";
if (wrongCount) wrongCount.textContent = "0";
if (progressBar) progressBar.style.width = "0%";
if (percentage) percentage.textContent = "0%";
if (message) message.textContent = "PRACTICE REGULARLY!";
});
}
});
  }
  if (document.readyState === "loading") {
document.addEventListener("DOMContentLoaded", initSmartAdviceQuiz);
  } else {
initSmartAdviceQuiz();
  }
})();
</script>
